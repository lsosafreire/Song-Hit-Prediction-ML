Predicting Hit Songs & Virality Using Audio Feature Engineering

Predicting hit songs using Spotify audio features, Billboard data, lyrics, Random Forest and XGBoost.

Project Overview - This project uses Machine Learning to establish if a song can be predicted as a hit based on its audio characteristics. 

Datasets - Four Kaggle datasets were used: Spotify Tracks Dataset, Billboard Hot 100 & More, Spotify Audio Features Dataset, and Spotify Million Song Lyrics Dataset.

Machine Learning Algorithms - We plan to compare four Machine Learning algorithms:

1. XGBoost

Uses gradient boosting and decision trees to improve predictions by learning from previous errors.

2. Logistic Regression

Estimates the probability of whether a song is a hit based on its features.

3. Random Forest

Uses multiple decision trees to classify songs as hits or non-hits.

4. Naive Bayes

Uses probability to classify songs based on their features.
